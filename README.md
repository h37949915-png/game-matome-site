# ゲームまとめサイト（静的サイト）

記事原稿（Markdown）から、依存パッケージなしで静的HTMLを生成するサイトの土台です。

> サイト名はまだ未定です。名前は `build.mjs` 先頭の定数 `SITE_NAME` 1か所で管理しているので、決まったらその1行を書き換えて再ビルドするだけで全ページに反映されます。

## 構成

- `build.mjs` — Node標準機能だけでMarkdownを変換するビルドスクリプト
- `content/articles.md` — 記事原稿（`##` 見出しで記事を区切る。冒頭のタイトル行と説明文は記事として扱わない）
- `dist/` — ビルド成果物（`index.html` / `articles/<slug>.html` / `style.css`）。生成物なので直接編集しない

スラッグとカテゴリの割り当ては `build.mjs` 内の `SLUGS` / `CATEGORIES` 配列（原稿の記事順に対応）で管理しています。記事を追加するときは、原稿に `##` 記事を足し、この2つの配列にも1件ずつ追加してください。

## ビルド

```sh
node build.mjs
# または
npm run build
```

`npm install` は不要です（依存パッケージなし）。`dist/` に一覧ページ・記事10本・CSSが出力されます。

## 公開手順（Altare）

1. このフォルダをGitHubリポジトリに push する（`dist/` も含める）
2. Altareのコンソールで **Apps → New app → GitHub repository** を選び、このリポジトリを接続する
3. Altareが静的サイトとして検出する。公開ディレクトリ（serveするルート）を `dist` に設定する
   - もしビルド済み成果物をそのまま配信する形で検出されない場合は、デプロイ前に `node build.mjs` を実行して `dist/` を最新化してから push する
4. デプロイが完了するとHTTPSアドレスが発行され、公開される
5. 以後の更新は「記事を書く → `node build.mjs` → GitHubに push」で自動デプロイされる

## メモ

- 記事内の `> [埋め込み：〜]` は「公式ポストの埋め込み枠」として点線ボックスで表示されます。実運用では、この枠の位置にXの埋め込みコードを差し込みます
- 「コメント」見出し配下の『〜』段落はコメント風ボックスで表示されます（現在は試作用のサンプル文です）
